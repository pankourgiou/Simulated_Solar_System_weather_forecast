Solar System Weather Station

Jump to a body — sized roughly by radius, ordered by distance from the Sun
Sun: NOAA SWPC (DSCOVR/ACE, L1 solar wind) — genuinely live. Moon: live astronomical position data (distance, illumination, phase) via the Farmsense API — the Moon has no atmosphere, so there is no "weather" to measure, but its position is real and changes by the minute. Mars: NASA's InSight lander, the only mission that ever gave Mars live weather, went silent in December 2022 when dust finally buried its solar panels — no replacement live feed exists yet, so Mars is honestly simulated within InSight's real recorded range. All other bodies: simulated within published mission ranges — no live atmospheric sensors exist there today.
